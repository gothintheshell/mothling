# It's a start, welcome to my blog

It's still a WIP, so some pages may be placeholders or not work as intended. This is part of the fun. 😹

## Technical Details

The blog is built using [Hugo](https://gohugo.io/), a static site generator written in Go. 

I've chosen to create this blog without a template, for maximum flexibility and learning of both HTML and CSS.
